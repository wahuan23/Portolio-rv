Coworking – Site Web

Cowork est une plateforme permettant de réserver facilement un espace de travail, que vous soyez étudiant ou professionnel.

Une utilisation simple et intuitive

Le but du projet est de simplifier la gestion des espaces de coworking grâce à un système de réservation en ligne. En quelques clics, les utilisateurs peuvent choisir l’espace qui leur convient.

Réservation avancée

Grâce à cette fonctionnalité, le système calcule automatiquement le coût des réservations selon l’espace choisi, la durée d’utilisation et les options ajoutées.

Fonctionnalité intelligente

Le système détecte automatiquement les réservations dépassant leur durée prévue et applique des pénalités. Plus le dépassement est long, plus le montant dû augmente. Les créneaux sont affichés en :
✔ Rouge : réservation dépassée
✔ Violet : réservé
✔ Vert : espace disponible

LES OUTILS UTILISÉS

Afin de développer une application plus avancée,
plusieurs technologies professionnelles ont été utilisées.

  • CodeIgniter (PHP)

    Framework MVC rapide et efficace pour créer une application web robuste.

  • PostgreSQL

    Base de données performante et fiable, idéale pour gérer les réservations, les tarifs et les calculs automatisés.
